# CRUD de Usuários – PHP + MySQL

Projeto CRUD (Create, Read, Update, Delete) desenvolvido em **PHP** utilizando **PDO** para conexão com **MySQL**, com interface simples em **HTML e CSS**.

O objetivo do projeto é demonstrar conhecimentos práticos em backend, organização de código e integração com banco de dados.

---

## 📌 Funcionalidades

- ✅ Listagem de usuários
- ✅ Cadastro de novos usuários
- ✅ Edição de usuários existentes
- ✅ Exclusão de usuários
- ✅ Conexão segura com banco de dados usando PDO
- ✅ Separação de lógica (PHP) e visual (HTML/CSS)

---

## ⚙️ Como Executar o Projeto

1. Instale o **XAMPP**
2. Inicie o **Apache** e o **MySQL**
3. Coloque o projeto dentro da pasta:C:\xampp\htdocs\
4. Crie um banco de dados no phpMyAdmin
5. Configure a conexão no arquivo `config.php`
6. Acesse no navegador:http://localhost/crud-php
